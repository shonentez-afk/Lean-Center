Центр TWI — токены для Amvera

Локальный генератор: три независимых 256-битных токена, без сетевых запросов. Совместимый формат HEX1 содержит только буквы и цифры.

Все значения ниже являются секретами. Не отправляйте их в чат и не делайте скриншоты. HEX1 — кодирование, не шифрование. Сохраните индивидуальные токены в разрешённом защищённом хранилище. Создание новых токенов заменяет предыдущие.

Этап «Запуск», имя LC_PILOT_USERS, включить «Это секрет», вставить HEX1 целиком без кавычек.
