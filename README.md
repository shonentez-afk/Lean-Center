# LEAN CENTER

Единый автономный центр СОП, ФРВ, TWI, компетенций, наставничества, аудита L1, планирования и аналитики.

Проектирование: 25.11.2026. Исходные контрольные версии будут храниться отдельно от нового приложения. Выделенный сервер и установка на каждый ПК не обязательны. Не размещать реальные производственные данные, ФИО, базы и секреты в GitHub.
