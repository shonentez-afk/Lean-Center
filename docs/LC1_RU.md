# LC1 — автономный фундамент (кандидат)
Рабочая оболочка: SQLite WASM (sql.js 1.13.0) и ECharts 5.6.0 встроены в один HTML, без сети и установки на ПК. Node/npm требуются только разработчику и CI для сборки. В приложении работают подразделения, сотрудники, профессии, оборудование, операции, назначения, поиск, архивирование, демо, дашборд. Остальные модули показывают честные заглушки, не считаются реализованными.
## Режимы
- Обычный пользователь редактирует рабочую копию (IndexedDB); каждое изменение содержит UUID и ожидаемую ревизию. Отправка пакета не удаляет очередь. После обновления из опубликованной базы принятые события удаляются из очереди по ID; конфликтующие сохраняются.
- Единственный уполномоченный издатель включает режим в разделе База и обмен. Принимает свои изменения/входящие пакеты. Применение пакета атомарно, дубликаты не применяются. Затем публикует новый SQLite-снимок и манифест с SHA-256 в Database/. Exchange/ содержит неизменяемые входящие пакеты, Backups/ — резервные копии. Не перезаписывать общую SQLite на SMB. ACL нужны извне; переключатель не является авторизацией.
- Если папка недоступна, издатель создаёт и скачивает снимок, сотрудники открывают его вручную; пакеты передаются файлами .leanpkg. Ручной режим и сетевую цепочку не смешивать. Копии .leanbackup содержат локальную базу, очередь, идентификатор устройства, состояние непубликации и хэш. Скачивание не подтверждает запись на диск; пользователь должен сохранить файл.
## Ограничения
Реальный SMB/корпоративный Edge не проверен. Только один издатель; нет блокировки между ПК, обнаруживаются развилки публикаций. Конфликт пакета отклоняется целиком; локальные конфликты разрешаются по одному с выбором опубликованного значения или повторным применением своей правки после просмотра данных и резервирования. Последующие события ждут разрешения первого конфликта. Автоматического слияния нет. Набор справочников v2, остальные сущности LC0 остаются подготовленной схемой. Локальные роли и хэши не являются подписью/защитой от злонамеренного пользователя. Фото, импорт Excel, полноформатная миграция Stage43/RC1, общий календарь и CAPA — будущие этапы. Вкладки СОП/TWI/аудита не меняют контрольные сборки.
