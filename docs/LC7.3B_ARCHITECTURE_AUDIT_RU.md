## Состав артефакта

## Достоверность и ограничения

Acorn 8.15.0 закреплён только как dev-зависимость. AST разбирает JS/MJS Lean Center, тесты и инструменты. Активные Stage43-скрипты из stage43-parts.json разбираются по отдельности; изолированные области видимости не разрешают межскриптовые глобальные функции. Оригинальный HTML, прокси Python, CSS, DDL, манифесты и сборка учитываются по инвентарю/границам; AST не доказывает восстановление их runtime. Статические вызовы через идентификатор, импорт, namespace и известный this в классе отделяются от вызовов через параметры и неразрешённые получатели. Условные вызовы и runtime-выбор не доказаны. SQL-литералы сопоставляются с реальной мигрированной схемой; при динамическом SQL или неизвестном получателе отмечается неопределённость. FK получены из PRAGMA, а не из догадок. Импорты с циклом не автоматически дефект. Последовательность контрольных точек сценария — маршрут проверки, не утверждение о прямой цепочке вызовов.
