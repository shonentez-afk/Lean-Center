- Владелец принял LC7.3A, замечаний нет; исходная продуктовая база 46b79c6ab23255a6b211afeadacd2be72f2ad803, Actions 45795444858 SUCCESS. Исходная ветка и `main` не изменяются.

- Исходный Stage43 закреплён Git blob 5e35036ce243fed74ea018ac8eaf5f6c4a3c3e45 в build_editor.mjs. Baseline не изменяется. Реальные данные предприятия не входят в аудит/артефакты.

## Воспроизведение

1. Node 22, `npm ci --ignore-scripts --no-audit --no-fund`.
2. `npm run test:architecture` — разрешение AST, области видимости, импорт под псевдонимом, class/this, неизвестные получатели, SQL и смешанная выборка мероприятий.
3. `npm run audit:architecture` — сбор модели из git ls-files, миграция пустой базы через действующее ядро, integrity и FK.
4. `npx playwright install chromium` и `node tests/lc73b-atlas-browser.mjs` — file:// offline, переходы, поиск, исходники, таблицы, ширина 390 px.
5. Полный продуктовый CI Windows/Linux остаётся обязательным; запуск отдельного workflow LC7.3B architecture atlas создаёт артефакт LeanCenter-LC7.3B-Architecture-Atlas. Скачайте ZIP, распакуйте, откройте LeanCenter-LC7.3B-Architecture.html. Отдельный артефакт, не устанавливаемый модуль Lean Center.

## Состав артефакта

- HTML без CDN и сервера: 7 режимов, интерактивный локальный граф, поиск по имени и пути, фильтры, входящие/исходящие ребра, возможное влияние до 3 уровней; точные ссылки GitHub на SHA и строки.
- atlas.json — машинно читаемый граф, узлы, исходники, SQL, неразрешённые вызовы, таблицы, миграции, циклы, сценарии и контрольные точки.
- source-inventory.csv — покрытие и SHA-256 каждого учтённого файла.
- unresolved-calls.csv — места, требующие разрешения; не приравнивать к дефектам или мёртвому коду.
- review.csv — реестр наблюдений, оснований, статусов и проверок.
- summary.json — фактическая статистика, версия схемы, ошибки разбора; скриншоты браузерного smoke.

## Достоверность и ограничения

Acorn 8.15.0 закреплён только как dev-зависимость. AST разбирает JS/MJS Lean Center, тесты и инструменты. Активные Stage43-скрипты из stage43-parts.json разбираются по отдельности; изолированные области видимости не разрешают межскриптовые глобальные функции. Оригинальный HTML, прокси Python, CSS, DDL, манифесты и сборка учитываются по инвентарю/границам; AST не доказывает восстановление их runtime. Статические вызовы через идентификатор, импорт, namespace и известный this в классе отделяются от вызовов через параметры и неразрешённые получатели. Условные вызовы и runtime-выбор не доказаны. SQL-литералы сопоставляются с реальной мигрированной схемой; при динамическом SQL или неизвестном получателе отмечается неопределённость. FK получены из PRAGMA, а не из догадок. Импорты с циклом не автоматически дефект. Последовательность контрольных точек сценария — маршрут проверки, не утверждение о прямой цепочке вызовов.

## Критерий закрытия

- Фактически построенный атлас на SHA, проверенный browser smoke, отчёт покрытия с явным списком исключений.
- Проверенные критические цепочки вызовов и таблиц, включая callback/event, bridge и смену состояния. Реальные сценарии создания, пересмотра, отмены, архивирования, конфликта, аннулирования и повторного открытия; отдельные тесты для найденных дефектов.
- Аудит всех 30 метрик, 23 сигналов, версий методик, связей с сотрудниками, фильтров и экспорта на смешанной базе; никакого молчаливого расширения или объединения несопоставимых данных.
- Не скрывать незакрытые кандидаты. Документировать причины, исправления и неизменённые решения. Полный продуктовый CI, пользовательская приёмка; реальные пилотные условия LC7.4 — отдельно.
