# LC8.1 TWI 03 — методическая стабилизация (R1, кандидат)

**Основание:** корпоративный стандарт организации производственного обучения СБЕ МИ, версия 03 от 30.01.2025, §§3.1–3.4, 4.1–4.6, приложения 1–17. Решение владельца от 28.11.2026: упростить основную работу, не превращать центр TWI в HRM/ERP. Этот документ — проект цифровой реализации, не новая редакция корпоративного стандарта.

## R1: реализовано в коде, до CI и пользовательской приёмки

- §§4.1.1–4.1.4: четыре явные категории основания нового назначения. Для связанной адаптации/стажировки и повторного обучения по новой редакции категория выводится из существующей связи, не из догадки об исторических фактах. Историческое неразмеченное основание остаётся не классифицированным. Отдельные нормативные ветвления ещё не завершены.
- §§4.1, 4.3: любой действующий сотрудник с кадровым назначением может стать обучаемым без предварительного оформления специальной бизнес-роли; назначение обучения не предоставляет дополнительных прав к данным. Не отменены сертификат, приказ и проверка права инструктора обучать операции.
- §4.3.5: в существующем реестре обучения добавлен общий план с точным составом строк и их версиями. Два реальных согласующих подтверждают весь состав один раз, с перепроверкой права каждого по каждой строке. Итоговые подтверждения записываются атомарно в существующую историю назначений. Изменение строки или утрата полномочий до второго подтверждения делает весь черновик устаревшим. Согласованный план сохраняется как исторический состав; изменённую строку включают в новый план. Прежняя одиночная процедура остаётся для исторических/исключительных случаев, не позволяет обойти текущий общий план.
- §3.2.2.2: форма протокола нескольких фактических этапов JI за одно сохранение. Только отмеченные и заполненные факты; сервер проверяет последовательность, фактическое время, длительность, результат, отдельного демонстратора при необходимости и подтверждение сторон. Один неверный факт откатывает весь пакет. Одиночная регистрация остаётся для повторов/исключений. Поддержка по-прежнему отдельные факты в течение месяца. Не введено автоматическое подтверждение этапов.
- §§3.4.2, 4.2: одна форма практической оценки и уровня МК (одна транзакция, две существующие записи, одно заключение и обратная связь). Не выдаёт допуск. Существующие раздельные формы пока сохранены для распределённых полномочий/истории. Проверки ОТ/теории и допуск видны как дополнительные; для опасной операции обязательная проверка безопасности сохранена. Действующие алгоритмы юридически значимых допусков не ослаблены.
- §4.2.5: собственные компетенции в карточке сотрудника: только его оценки и действующие требования его профессии. Не выдаёт право читать общую матрицу; отдельная проверка каждого факта. Обеспеченность по действующим компетенциям отображается отдельно от старого консервативного показателя с зарегистрированным допуском.
- Схема предметных данных v17 сохранена. Новые служебные таблицы LC8.1 создаются при первой записи и сохраняются в полном снимке. Старые события, источники и учётные записи не переписываются. Проверки прав, двусторонних подтверждений, опасных работ, источников СОП и архивных оценок сохранены.
- Добавлена отдельная CI-ветка без передачи SSH-ключей и без обновления VPS. Регрессии: сотрудник без роли обучаемого, согласование двух строк, запрет частично видимого плана и двойного голосования, устаревший состав, атомарный протокол и оценка, отсутствие автоматического допуска, личная МК, повторное открытие снимка.
