# ROADMAP
| Этап | Пакет | Критерий завершения |
|---|---|---|
| LC0 | Baselines, функциональная карта, архитектура, физическая DDL | Git SHA исходников, схема и документация |
| LC1 | Offline storage, миграции, обмен, shell, ECharts | Тесты SQLite и два ПК; безопасный fallback |
| LC2 | Единые справочники и импорт XLSX | Дедупликация, история, связи |
| LC3 | СОП, библиотека, версии, ФРВ | Регрессия Stage43 и корпоративских форматов |
| LC4 | Компетенции, TWI, наставники | Практическая оценка, coverage, планы развития |
| LC5 | Аудит L1, RC1 migration, мобильный импорт | Версии критериев и все 15 методологических находок классифицированы |
| LC6 | Общий календарь, CAPA, аналитика | Связанные записи, объяснимые KPI, эффективность |
| LC7 | ИИ, интеграционные тесты, пилот | Безопасность, инструкции, реальные скриншоты, резервирование |

Открытые вопросы: файловые политики и ACL, корпоративская шкала компетенций, правила подтверждения наставников, новые версии L1, сроки L2/L3, регламент издателя master, объём фото, разрешение ИИ. Не блокировать автономный прототип ожиданием методических ответов: настройки/демо явно маркировать.
