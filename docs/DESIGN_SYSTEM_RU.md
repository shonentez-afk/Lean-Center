Дата 25.11.2026. Дизайн в стиле ТЕХНОНИКОЛЬ, не официальный утверждённый макет бренда.

Не заявлять копию интерфейса сайта.
## Правила интерфейса
Основной светлый фон, белая верхняя панель, тонкая красная полоса, серо-синяя навигация, прямоугольные панели, контрастные заголовки; красный для главного действия и активной навигации. Светло-серые поверхности и границы. Тёмная тема — вспомогательная адаптация. Семантические цвета успеха/предупреждения/ошибки — отдельные UI-токены, не брендовые утверждения. Цвет никогда не единственный признак ошибки.
Все модули получают единые CSS tokens, панели, заголовки, кнопки, таблицы, поля ввода, статус, графики и responsive-правила. Иконки — простые оригинальные контуры; без внешнего CDN. Навигация равноправная, не имитировать работающие модули. На дашборде показывать только фактические данные. Нейтральные столбцы ECharts; отдельная смысловая палитра аналитики (LC1.3). 
## Защита baseline
LC1.2 меняет только presentation, versioned release, CI и документацию. SQL schema v2, core, network, storage и кэш без изменений. Обновление через неизменный index.html. Сохранить LC1.1 в main и новую версию в отдельной ветке до приёмки. Не копировать реальные тестовые базы в GitHub.

## Предоставленный шрифт — 25.11.2026
Локально проверен пользовательский TTF: Proxima Nova Regular, версия 2.003, family Proxima Nova / legacy family Proxima Nova Rg, weight 400, полная базовая русская кириллица и Ё/ё; copyright Mark Simonson, 2005. CSS и ECharts учитывают оба семейства. При наличии только Regular разрешена синтетическая жирность для читаемой иерархии; предпочтителен настоящий Bold при наличии лицензированной версии. Сам файл не загружается в GitHub и не входит в ZIP. Если корпоративные ПК уже имеют лицензированный шрифт, он используется автоматически. Если нет — Arial без установки. Для централизованной поставки требуется подтверждённое право встраивания/распространения шрифта в автономном файловом приложении; публичная web-лицензия автора предусматривает WOFF/WOFF2, не конвертировать TTF самостоятельно. Источник: https://www.marksimonson.com/licensing/. Не считать наличие TTF или fsType разрешением на распространение.

## Аналитическая палитра — LC1.3 (согласовано пользователем)
Фирменный красный интерфейса сохраняется для активной навигации и основных действий. В аналитике цвет определяется смыслом данных. Общий код: src/analytics/palette.js. Все обычные графики и будущие матрицы должны использовать эти правила.

| Состояние | Светлая тема | Тёмная тема | Применение |
|---|---|---|---|
| Факт | #242E40 | #A9BCD4 | Обычные числовые показатели и количественные ряды |
| Сравнение | #2563EB | #74A8FF | Динамика и сравнение |
| Соответствует | #27965A | #69CA90 | Подтверждённое выполнение / соответствие |
| Требует внимания | #A17600 | #F0CE57 | Жёлто-охристый предупредительный цвет |
| Риск | #C46708 | #FFAB62 | Отклонение, риск |
| Критическое отклонение | #E30613 | #FF777F | Подтверждённое критическое нарушение |
| План | #85878C | #A6ADB8 | Контур / пунктир + подпись |
| Не оценено / неприменимо | #BFC0C0 | #626E80 | Контрастный контур, разные знаки ? / — и штриховка |

Жёлтый и оранжевый на светлом фоне скорректированы относительно предложенной палитры для контрастности видимых графических элементов; тёмная тема имеет самостоятельные цвета. Для категорий используются нейтральные серо-синие, синие и близкие холодные оттенки. При сравнении нескольких рядов сохранять подписи, легенду, при необходимости форму/штриховку; цвет не единственный носитель смысла. Матрицы обязаны различать нулевой подтверждённый уровень, отсутствие оценки, неприменимость и истёкший срок. Шкала и пороги определяются согласованной методикой каждого модуля; palette.js не присваивает оценки и не вводит пороги. Условные примеры процентов из обсуждения не являются корпоративской методикой. В LC1.3 реально изменён только график количества записей и добавлен общий модуль палитры; будущие матрицы, аудиты и KPI ещё не реализованы. Светлая/тёмная тема проверяются отдельно. База и сетевой обмен неизменны.
