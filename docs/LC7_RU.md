## LC7.1 — текущий кандидат

- Дашборд и помощник используют `src/modules/training/center-attention.js`, который извлекает существующие 23 строки внимания (одна из двух ветвей банка вопросов), их числа, определения и переходы. Нет новой таблицы рекомендаций. Приоритеты — техническая сортировка предложений, не новый корпоративский норматив. Годовая норма L1 до конца года является планированием, не просрочкой. Числа разных выборок не суммировать.
- `src/modules/assistant/screen.js`: локальный экран, категории, явное объяснение и переход в родной модуль. При отсутствии сотрудников или действующих СОП выводится недостаточность исходных данных, а не ложная готовность.
- `src/modules/assistant/cloud.js`: фиксированный endpoint и модель из Stage43, task=chat, только заранее определённые описания до 8 тем; никаких персональных данных, чисел из БД, текста пользователя, исходников или финансовых сумм. Точный запрос виден до отправки; согласие не запоминается, требуется каждый раз. Ограничение времени 30 секунд и размера ответа 32 КиБ, валидация JSON и кодов тем, вывод текстом, без HTML и команд. Нет токенов в приложении, автоматической проверки подключения, записи данных или автоматического создания задач. Сам факт выбора темы может быть конфиденциальным; облако только по разрешению предприятия. Нельзя считать этот режим корпоративской авторизацией.
