## Реализовано в коде LC5.1
- Оценивание единым компонентом: основной выпадающий список L1 — пусто/0/1; исключения вынесены в отдельное раскрытие «Не удалось оценить» с обязательным основанием, не являются дополнительными баллами. Мобильный L1 аналогичен. Практика сохраняет 0/1, самооценка 1–5, матрица 1–4; ни один критерий исходных встроенных форм не изменён.
- Практика: отдельный журнал фактических оценок и карточка конкретной записи, новое наблюдение через действующее согласованное назначение с завершёнными пробами; сохраняется существующий путь из обучения, ОТ/теория/квалификация/допуск. Самооценка — тот же стиль журнала и карточки, версионные фильтры, исторические результаты.
- Действия: FK на исходную самооценку/практическую оценку и критерий, проверки субъекта, запрет дублей, двусторонние переходы, источник в едином реестре. Переобучение обучаемого только при заключении «Не соответствует». Даже при положительном общем заключении можно создать корректирующее действие по реально невыполненному критерию. Для эффективности повторного обучения/критерия — сопоставимая последующая практика и положительный критерий; повторный провал исключает подтверждение. Самооценка — вручную согласованное развитие, не автоматически нарушение. Независимое подтверждение с доказательством; сам факт повышения самооценки не доказывает эффект.
- Карточка сотрудника: точные ссылки на результаты, баллы, связанные мероприятия с ролью оцениваемого/оценщика/наставника/автора самооценки; фильтр журналов из карточки. Профиль наставника: переходы на общие реестры, без собственного дублирования. Существующие права, сертификаты и назначения сохранены.
- Аналитика центра: три вкладки (L1, практика, самооценка), методика, период, сотрудник, подразделение и смена, динамика, критерии, разделы, матрица наблюдений, отдельные заключения практики / распределение уровней самооценки, связанные мероприятия. Смешивания версий и шкал нет. 
- Дашборд: объём практических оценок, отрицательные заключения, самооценки за месяц и требующие решения последние отрицательные результаты без незавершённого мероприятия. Это информационные показатели, не автоматические допуски/порог.
- Добавлена миграция v11→v12 без переписывания фактов; предыдущие версии пакетов проверяются, новые связи не попадают в старую схему. Тесты на миграцию, реальные формы, источники, ограничения, аналитическую раздельность, employee dossier, backup; расширены browser сценарии. Статус CI проверять по актуальному коммиту.

## Что ещё доработать, не выдавать за готовое
1. Календарь: отдельные плановые повторные практические оценки и самооценки с ответственным, явным фактом выполнения, общие сроки; сейчас сроки связанных задач уже выводятся из единого реестра, отдельных типов планирования этих двух форм нет.
2. Сопоставление самооценки и аудита L1: утвердить карту общих наблюдаемых навыков/критериев; не сравнивать 1–5 с процентом 0–1 напрямую. Плановое развитие наставника, проверка независимым наблюдателем, динамика по совпадающим критериям.
3. Досье и «Мой план»: план/факт, запланированные оценки, просроченные действия, ожидающие проверки, сертификаты и полномочия со сроком, статус пересмотра СОП. Не дублировать текущие задачи/матрицу. 
4. Корпоративская оценка СОП и чек-лист конструктора: единый стиль реестра/карточки, задачи из конкретного критерия, методики и версии, история повторной проверки, дашборд и отдельная аналитика. Не смешивать взвешенную и бинарную формы.
5. ФРВ: отдельная аналитика потерь, причин, план/факт улучшений по сопоставимым замерам, связи с мероприятиями и версиями СОП; не рассчитывать ROI из неподтверждённых измерений.
6. Переобучение: единая очередь оснований (СОП, дефицит навыка, практика, L1, развитие), назначение/срок/ответственный, контроль дублирования, закрытие по реальному подтверждённому результату, эффект до/после по сопоставимому контексту.
7. Наставники/сертификация: обзор оснований, открытых действий и истории наблюдений; калибровка оценщиков; утверждение требований ОТ/производства, критических критериев и нормативных порогов отдельно. Не вводить выдуманные интервалы L2/L3.
8. Крупная регрессия на Windows/Linux, реальные формы Excel, мобильные устройства, рабочая копия базы, SMB/ACL. Остальные методологические ограничения из LC5_RU.md сохраняются.
