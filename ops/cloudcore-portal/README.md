# Мобильный портал CloudCore QA

Портал размещается в домашнем каталоге пользователя lean-deploy на VPS CloudCore и слушает только адрес 127.0.0.1:18083. Именованный Microsoft Dev Tunnel lean-center-ops пропускает владельца через GitHub. Для туннеля и порта сохраняются исходные заголовки Host и Origin. Порт приложения Lean-Center использует отдельный туннель и сохраняет прежний адрес.

Портал показывает состояние тестового приложения и туннеля, исходный SHA, номер выпуска, метаданные последних копий и журнал операций. Он выполняет только два действия, snapshot и restart, через существующий контроллер тестового стенда. Список копий содержит размер файла базы. HTTP-запросы не скачивают копии и не открывают сырые журналы, конфигурацию или секреты. Запрос на изменение требует правильный Origin и токен текущего процесса портала, полученный с его страницы. Контроллер сериализует действия с ночным резервированием и выпусками.

На VPS файлы server.mjs, index.html, portal.css и portal.js располагаются в каталоге ~/lean-center-cloudcore-qa/private-portal/app. Скрипт run-portal.sh расположен на уровень выше. Там же хранятся идентификатор туннеля, состояние и журнал портала. Его задание запуска при загрузке находится в расписании lean-deploy. Node.js берётся из первой проверенной установки CloudCore. Для развёртывания приложения используется владелец уже настроенного GitHub-доступа на VPS. Изменение этих файлов в репозитории само по себе не переключает сайт Lean-Center.
